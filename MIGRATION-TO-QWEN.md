# Миграция с Claude Code на Qwen Code

Этот проект был обновлён для поддержки Qwen Code (https://github.com/QwenLM/qwen-code.git) в дополнение к Claude Code. Все функциональные возможности workspace сохранены.

## Что изменилось

1. **Новая структура файлов:**
   - Добавлен файл `QWEN.md` - основная ориентация для Qwen Code
   - Добавлена папка `.qwen/` с конфигурацией для Qwen Code
   - Обновлён `.gitignore` для поддержки файлов Qwen Code
   - Обновлён `README.md` с упоминанием Qwen Code

2. **Полная совместимость:**
   - Все команды (`/start`, `/sync`, `/save`, `/promote-to-department`, `/workspace-help`, `register-repo`) доступны как в Qwen Code, так и в Claude Code
   - Настройки разрешений (`settings.json`) синхронизированы между обеими версиями
   - Скрипт `refresh-commands.sh` адаптирован для Qwen Code

3. **Двойная поддержка:**
   - Проект поддерживает одновременную работу с Claude Code и Qwen Code
   - Файлы конфигурации для обеих систем существуют параллельно
   - Можно использовать ту систему, которая предпочтительнее

## Как использовать Qwen Code

1. Установите Qwen Code по инструкции на https://github.com/QwenLM/qwen-code.git
2. Откройте этот репозиторий в Qwen Code
3. Используйте команды как обычно:
   - `/start` для настройки workspace
   - `/sync` для синхронизации
   - `/workspace-help` для справки

## Отличия в конфигурации

- **Для Qwen Code:** конфигурация в `.qwen/`
- **Для Claude Code:** конфигурация в `.claude/`

Обе конфигурации синхронизированы и содержат одинаковые настройки разрешений.

## Обновление существующих установок

Если у вас уже есть настроенный workspace с Claude Code:

1. Просто откройте проект в Qwen Code
2. Все мозги в `brains/` останутся доступными
3. Настройки будут автоматически подхвачены из `.qwen/`
4. Для загрузки команд мозга перезапустите Qwen Code после первого `/sync`

## Преимущества Qwen Code

- Открытый исходный код
- Активное развитие
- Поддержка различных языков программирования
- Гибкая конфигурация

## Советы по миграции

1. **Тестирование:** Сначала протестируйте Qwen Code на копии вашего workspace
2. **Резервное копирование:** Убедитесь, что все мозги синхронизированы (`/sync`)
3. **Параллельная работа:** Можно работать одновременно в обеих системах для плавного перехода
4. **Обратная связь:** Сообщайте о проблемах в репозитории проекта

## Помощь и поддержка

- Используйте `/workspace-help` в Qwen Code для получения справки
- Читайте `QWEN.md` для понимания структуры workspace
- Обращайтесь к документации Qwen Code для специфичных вопросов

Проект продолжает развиваться и поддерживать обе системы для максимальной гибкости использования.
