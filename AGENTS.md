# Корень репозиториев, Multi-Brain Workspace (ориентация для Codex)

**ВНИМАНИЕ:** Этот файл является устаревшей версией документации. Для использования Qwen Code смотрите файл `QWEN.md` как основную ориентацию.

Это зеркало Codex для файла `CLAUDE.md`. Оба файла содержат одинаковый контент и должны редактироваться вместе. Ориентируйтесь из этого файла только при использовании Codex или Claude Code.

Это корень репозиториев: общий родительский уровень топологии Infinite Brain и папка, которую вы открываете. Его задача — направлять вашу работу в нужный мозг и синхронизировать каждый мозг. Есть два способа запуска, и они дополняют друг друга. Основная форма — мульти-мозговой workspace: несколько мозгов, смонтированных в `brains/`, с которыми вы работаете. Вторичная форма — корень реестра для операции, работающей со многими репозиториями.

## Workspace: мозги, смонтированные в `brains/`

`brains/` содержит мозги, с которыми вы работаете, каждый — независимый git-репозиторий, клонированный через `/start`:

- общий мозг (мозг компании или продвинутый мозг отдела): основная рабочая поверхность;
- ваш индивидуальный мозг (`individual-<имя>/`): ваш личный слой для набросков и исследований.

Если `brains/` пуст, выполните `/start`, и он клонирует ваши мозги.

### Правило маршрутизации

1. **По умолчанию используйте общий мозг** для реальной, общей работы или чтения канона. Ссылайтесь на его канон по пути, никогда не копируйте его.
2. **Индивидуальный мозг для всего нового, неопределённого или разрушительного.**
3. **Проверенная индивидуальная работа продвигается наверх**, никогда не редактируется в общем мозге напрямую; `/sync` направляет основные изменения в ветку `proposal/<slug>-<topic>` для ревью.

`.claude/CAPABILITIES.md` (регенерируемый через `/sync`) перечисляет, что содержит каждый смонтированный мозг, чтобы вы могли направлять работу в правильный мозг.

### Команды

- `/start`: устанавливает доступ к git (по умолчанию GitHub), создаёт или клонирует каждый мозг в `brains/` (на совершенно новом запуске он создаёт приватные удалённые репозитории и перенаправляет origin стартового клона на собственный репозиторий человека), проверяет и регистрирует каждый мозг, выполняет `/sync`.
- `/sync`: пушит индивидуальный мозг свободно; пушит содержимое общего мозга в общую ветку; направляет основные изменения общего мозга в ветку предложения; тянет последние обновления; обновляет копируемый слой команд и индекс возможностей.
- `/save`: коммитит каждый мозг, без пуша. `/promote-to-department`: упаковывает индивидуальную работу для ревью. `/workspace-help`: объяснение простыми словами.

### Как работают собственные команды мозга здесь

Claude Code (и Codex) загружают только адаптерную папку этого корня, никогда дочернего репозитория. Поэтому `/start` и `/sync` копируют `.claude/{commands,skills,agents,rules}` каждого смонтированного мозга в этот корень, чтобы инструменты мозга стали командами здесь (после перезапуска). Скопированная команда выполняется против исходного мозга (см. `.claude/COPIED-FROM.md`). Собственные команды workspace никогда не перезаписываются.

## Корень реестра (вторичный: запуск многих репозиториев)

Операция, работающая с более чем горсткой смонтированных мозгов плюс репозитории приложений, также использует этот корень как реестр. Дети живут в `internal/` (принадлежащие) и `external/` (клиентские или совместно управляемые, сгруппированные в `external/<группа>/`), каждый — независимый репозиторий, известный только через запись в `repo-registry/`. `repo_kind` может быть `brain`, `app` или `mixed`; мозг также имеет `brain_tier` (`individual`, `department`, `company`). Зарегистрируйтесь через `ADD-A-BRAIN.md` или команду `register-repo`. Реестр — полная карта; `brains/` — подмножество, с которым вы активно работаете.

## Что этот корень никогда не содержит

Никакого собственного содержимого мозга. Мозги в `brains/` и дети в `internal/`/`external/` — независимые репозитории с собственными удалёнными репозиториями; этот корень игнорирует их содержимое в git и не предоставляет резервного копирования. Копируемый слой команд и индекс возможностей генерируются, игнорируются git, регенерируются через `/sync`, доступны только для чтения ниже по потоку и никогда не являются вторым источником истины. Никаких секретных значений здесь нет.
