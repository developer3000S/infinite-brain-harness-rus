# /save: сохранить мою работу

Закоммитить работу в каждом мозге в `brains/` с именем человека. Только коммиты; пушинг и логика веток ревью — задача `/sync`.

## Шаги

1. Идентичность. Убедитесь, что `user.name` и `user.email` установлены в каждом мозге; спросите один раз, если пусто.
2. Индивидуальные мозги. Для каждого `brains/individual-*` с изменениями простаджить и закоммитить с коротким
   описательным сообщением, например `<имя>: черновик идей для весенней кампании`.
3. Общие мозги. Для каждого общего мозга закоммитить ТОЛЬКО то, что эта сессия создала в `outputs/` или
   `sessions/`, с сообщением, начинающимся с имени человека. Если diff касается чего-либо вне этих
   папок (основное изменение), НЕ коммитьте это здесь: оставьте и скажите в одной строке, что основное изменение лучше
   обработать через `/sync`, который направит его в ветку ревью.
4. Отчитайтесь в одном или двух простых предложениях, что сохранено где. Если ничего не изменилось, скажите так и остановитесь.

Не пушите из этой команды. Пушинг — задача `/sync`.
